# 会话与记忆

模型是无状态的，「记忆」全是后端每次调用时重新拼进上下文的内容，所以它受上下文窗口限制、按 token 付费，也是一个攻击面。会话记忆（这个对话的历史）应该以服务端为准，不信任客户端传来的历史，因为客户端能伪造 assistant 消息或工具结果。长期记忆（跨会话的事实和偏好）要设计写入（抽取、去重、更新）和读取（按问题检索、限量）两条路径，还要支持用户删除。

- **存什么是取舍**：DocPilot 只把最终答案放回历史，token 成本低、注入不会累积，但追问时要重新检索。
- **历史超长**：滑动窗口、保留头尾、滚动摘要、先丢旧的工具结果；改动历史开头会让 prompt cache 失效。
- **记忆投毒会持续重放**：只把用户本人的明确陈述写进长期记忆，按用户隔离，记录来源。
