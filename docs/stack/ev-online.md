# 线上回归与 A/B

离线 eval 只覆盖想到的问题，线上评估看真实发生的问题。信号分四类：隐式的（重新生成、追问、放弃，量大但含义模糊）、显式的（点赞点踩，含义清楚但稀疏且有偏差）、自动化检查（对 trace 跑规则，再对采样跑 judge）、业务指标。还要监控漂移：问题分布、语料、供应商模型的变化。比较两个版本用 A/B 实验：按用户分组，事先定好主指标、护栏指标（延迟、成本、错误率）和样本量，不要偷看就停；检索策略的比较可以用更灵敏的 interleaving。

- **不调用模型就能算的线上指标**：幻觉引用率（引用标记数减去回库校验成功的数量）、拒答率、截断率、步数耗尽率、工具错误率。
- **常见错误**：偷看、样本比例失配、新奇效应、只看平均值。
- **闭环**：线上的失败案例去掉个人信息后，加进离线数据集。
